# Lobar Function Signs of the Brain — MCh Neurosurgery seminar

Source files for a 63-slide seminar deck: lobar functions and bedside tests, localization of lobar signs, blood supply of the brain, localization of the infarct-related artery, and neurosurgical application (eloquence grading, mapping).

- `project/deck.json` — slide order and sections
- `project/slides/*.html` — one file per slide (speaker notes in each `<aside>`)

Every claim on a slide cites a numbered reference; the full list (59 sources: standard textbooks and primary papers) is on the last five slides (`refs1`–`refs5`).
